# BizLens AI 开发日志

## 2026-09-14

### 已完成

- 清理拷贝遗留的论坛、聊天室、私信、板块、帖子、WebSocket 和对应前端页面、Mock 数据与图片资产。
- 保留登录认证、用户基础模型、AI Provider、AI 对话和 AI 角色管理。
- Maven 数据库驱动从 MySQL 切换为 PostgreSQL，PageHelper 方言同步切换。
- 删除开发配置中的硬编码数据库和 Redis 凭据，改为环境变量覆盖。
- 新增 PostgreSQL 建表脚本，覆盖 AI 在线数据、代码知识库索引、Code Graph 关系和安全审计。
- 新增 `AiSafetyGuard`，拦截常见 Prompt Injection，并阻止模型输出源码、SQL、配置和密钥；流式接口改为安全检查后再发送结果。
- 初始化项目 README、开发文档和本开发日志。

### 校验

- `mvn -q -DskipTests package`：通过。
- `pnpm install --frozen-lockfile`：通过，按锁文件安装 154 个依赖。
- `pnpm run build`：通过；Vite 仅提示主 bundle 超过 500 kB。
- `npm run build` 未采用：当前机器 Volta 的 npm 安装缺少 `npm-prefix.js`，项目统一使用 pnpm 验证。
- `pnpm run test`：未通过，Vitest 4 与当前 Vite 包导出产生 `./module-runner` 启动兼容性错误；本次未升级依赖，已列为测试环境待办。

### 已知后续工作

- 将启动类重命名为 `BizLensAiApplication`，Maven 坐标统一为 `com.bizlens:bizlens-ai` / `bizlens-ai-service`，前端 npm 包名统一为 `bizlens-ai-web`，移除旧项目 `404forum` 标识。
